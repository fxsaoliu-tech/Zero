# Zero

Zero is a modern firearm framework mod for Minecraft Forge.

The goal of Zero is to provide a high-quality FPS weapon experience in Minecraft, including smooth first-person animations, weapon systems, attachments, and realistic shooting mechanics.

This project is built from scratch with its own gameplay systems, rendering pipeline, animation framework, and resource structure.

## Features

- First-person firearm rendering system
- Custom weapon animation framework
- Weapon recoil system
- Shooting and projectile system
- Attachment support
- Reload and inspection animations
- Custom HUD interface
- Client-server synchronized weapon logic
- Extensible weapon data system

## Design Goals

Zero focuses on creating a more immersive FPS experience inside Minecraft:

- Smooth weapon movement
- Detailed animation transitions
- Realistic weapon handling
- Flexible modding support
- Performance-friendly architecture
