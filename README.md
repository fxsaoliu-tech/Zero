# Zero

Zero is a modern firearm framework mod for Minecraft Forge.

The goal of Zero is to provide a high-quality FPS weapon experience in Minecraft, including smooth first-person animations, weapon systems, attachments, and realistic shooting mechanics.

This project features its own gameplay systems, rendering pipeline, animation framework, and resource structure.

## Features

- First-person firearm rendering system
- Custom weapon animation framework
- Extensible weapon data system

## Design Goals

Zero focuses on creating a more immersive FPS experience inside Minecraft:

- Smooth weapon movement
- Detailed animation transitions
- Realistic weapon handling
- Flexible modding support
- Performance-friendly architecture

## Credits & Acknowledgements

Zero is an independent Minecraft firearm framework project.

During development, some technical ideas and implementation approaches were studied from existing open-source Minecraft firearm mods, including:

- **Timeless and Classics Zero (TACZ)**  
  https://github.com/MCModderAnchor/TACZ

- **Flan's Mod**  
  https://www.flansmod.com/

These projects provided valuable references and inspiration in areas such as:

- Weapon system architecture
- Ray tracing approaches
- Animation concepts
- Gameplay mechanics design

Some code structures and technical approaches were influenced by these projects.

Zero does not redistribute original assets from TACZ or Flan's Mod.

Special thanks to the developers and contributors of TACZ and Flan's Mod for their excellent work and inspiration.
